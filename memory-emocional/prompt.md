Quiero que crees una mini web infantil en HTML, CSS y JavaScript puro, en un solo archivo index.html.

Nombre del juego:
“Memory de emociones”

Objetivo:
Ayudar a niños de 4 a 8 años a reconocer emociones jugando a encontrar parejas.

Emociones que debe trabajar SOLO:
- Enfado
- Alegría
- Miedo
- Tristeza
- Amor

No incluyas otras emociones.

Estilo visual:
- Infantil, alegre y moderno.
- Colores vivos pero equilibrados.
- Paleta neutra válida para niñas y niños.
- Fondo claro y limpio.
- Tarjetas redondeadas con sombras suaves.
- Botones grandes y fáciles de pulsar.
- Usa tonos como amarillo suave, verde menta, azul cielo, coral, naranja cálido, lila suave y blanco crema.
- No uses estética excesivamente rosa ni excesivamente azul.
- Añade corazones, estrellas, nubes, rayitos, hojas o círculos decorativos.
- Responsive para móvil y ordenador.
- Sin personajes con copyright.
- Sin imágenes externas obligatorias.
- Usa emojis o ilustraciones simples creadas con CSS.
- Que parezca una mini app infantil cuidada, no una página básica.

Estructura:

1. Pantalla de inicio
Título:
“Memory de emociones”

Subtítulo:
“Encuentra las parejas y descubre qué siente cada corazón.”

Botón:
“Empezar juego”

2. Pantalla del juego
Crear un tablero de cartas boca abajo.

Cada emoción debe tener 2 cartas:
- Una carta con el nombre de la emoción.
- Una carta con un icono o emoji que represente esa emoción.

Parejas:
- Alegría + 😊
- Tristeza + 😢
- Enfado + 😡
- Miedo + 😨
- Amor + ❤️

Total:
10 cartas.

3. Funcionamiento
- Las cartas deben aparecer mezcladas aleatoriamente.
- El niño puede girar dos cartas por turno.
- Si forman pareja correcta, se quedan descubiertas.
- Si no forman pareja, se vuelven a tapar después de un momento.
- Añade contador de intentos.
- Añade contador de parejas encontradas.
- Al completar todas las parejas, mostrar pantalla final.

4. Feedback educativo
Cuando encuentra una pareja correcta, mostrar un mensaje breve:

Alegría:
“¡Alegría! La sentimos cuando algo nos hace sonreír o nos ilusiona.”

Tristeza:
“Tristeza. A veces el corazón necesita consuelo y descanso.”

Enfado:
“Enfado. Nos avisa de que algo no nos gusta o sentimos que no es justo.”

Miedo:
“Miedo. Aparece cuando necesitamos sentirnos seguros.”

Amor:
“Amor. Lo sentimos cuando cuidamos, ayudamos y queremos.”

5. Pantalla final
Mostrar:
- Mensaje: “¡Lo has conseguido!”
- Número de intentos.
- Mensaje educativo:
“Todas las emociones son importantes. Aprender a reconocerlas nos ayuda a cuidar nuestro corazón.”
- Botón: “Jugar otra vez”

6. Requisitos visuales
- Cartas grandes y fáciles de pulsar en móvil.
- Animación suave al girar la carta.
- Diseño responsive.
- En móvil, el tablero puede verse en 2 columnas.
- En ordenador, el tablero puede verse en 5 columnas.
- Parte trasera de la carta con un corazón, estrella o signo de interrogación.
- Al acertar una pareja, la carta puede quedar con un pequeño brillo o borde especial.
- Usa colores suaves y alegres, pero no demasiado infantiles ni recargados.

7. Requisitos técnicos
- Todo en un único archivo index.html.
- HTML, CSS y JavaScript puro.
- Sin librerías externas.
- Código limpio, ordenado y comentado.
- Preparado para modificar emociones fácilmente.
- Preparado para sustituir emojis por imágenes reales más adelante.
- No uses sonidos externos.
- No uses imágenes externas obligatorias.

Devuélveme el archivo completo index.html listo para copiar y pegar.
